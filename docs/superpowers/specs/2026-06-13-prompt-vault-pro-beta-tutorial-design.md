# Prompt Vault Pro Beta Tutorial Video Design

## Goal

Produce four polished tutorial videos that teach beta testers how to use
Prompt Vault Pro:

1. 90-second overview in landscape 16:9.
2. 90-second overview in vertical 9:16.
3. Detailed 3-4 minute walkthrough in landscape 16:9.
4. Detailed 3-4 minute walkthrough in vertical 9:16.

All versions use real application footage, friendly AI narration, burned-in
captions, Prompt Vault Pro's green visual identity, and privacy-safe demo data.

## Audience

The primary audience is non-technical beta testers who need to understand the
product without setup assistance. The videos should assume no prior knowledge
of prompt-management software.

## Creative Direction

Use a guided product-tour format. Real application screens remain the visual
focus, supported by:

- Soft green cursor rings and click indicators.
- Smooth zooms toward the active control.
- Short lower-third captions.
- Brief branded opening and closing cards.
- Calm, friendly AI narration at an approachable pace.
- Center-safe composition that can be reframed for vertical video.

Do not use an onscreen avatar. Do not show personal email addresses, account
menus, OAuth credentials, private documents, browser bookmarks, or unrelated
tabs.

## Required Product Preparation

Before recording, improve prompt-form validation so an attempted save with a
missing required title:

- Moves focus to the Title field.
- Shows a prominent summary near the Save button.
- Uses plain language: "Add a title before saving your prompt."
- Does not clear the draft.

This prevents beta testers from mistaking an incomplete form for a saved
prompt.

## Demo Content

Use a dedicated demonstration prompt:

- Title: `Restaurant Menu Improvement`
- Description: `Find practical ways to improve a restaurant menu.`
- Category: `Restaurants`
- Platform: `ChatGPT`
- Tag: `Menu planning`
- Prompt content: a short, non-sensitive restaurant menu analysis prompt.

Use a generic sample menu PDF or text file if a knowledge-file upload is shown.
The file must contain fictional data.

## Quick Video Storyboard

Target duration: 75-100 seconds.

1. **Opening card, 4 seconds**
   - Text: `Welcome to Prompt Vault Pro`
   - Subtext: `Create. Organize. Reuse.`

2. **Sign in and library, 10 seconds**
   - Show Google sign-in without revealing an email address.
   - Arrive at the Prompt Library.
   - Narration explains that the library keeps reusable prompts together.

3. **Create a prompt, 30 seconds**
   - Click New prompt.
   - Enter title, description, and prompt content.
   - Select Restaurants and ChatGPT.
   - Explain that tags are optional labels used for organization.
   - Save and show the confirmation.

4. **Find and reuse, 25 seconds**
   - Return to the library.
   - Sort by Recently Added.
   - Search for `Restaurant`.
   - Open the saved prompt and copy it.

5. **Closing card, 8 seconds**
   - Text: `You’re ready.`
   - Subtext: `Add a prompt, test the workflow, and share your beta feedback.`
   - Show the production app URL.

## Detailed Video Storyboard

Target duration: 3-4 minutes.

1. Branded introduction and product purpose.
2. Sign in and navigation overview.
3. Create a prompt and explain each required field.
4. Explain category, AI platform, rating, favorites, folders, and tags.
5. Explain that knowledge files are optional supporting documents and must
   also be uploaded when using the prompt in another AI product.
6. Save the prompt and show its detail page.
7. Copy the prompt for use elsewhere.
8. Edit the prompt and explain automatic version creation.
9. Search, filter, sort by Recently Added, and clear active filters.
10. Show templates and import as optional shortcuts.
11. Explain useful beta feedback:
    - Errors or failed actions.
    - Confusing labels or instructions.
    - Missing workflows.
    - Mobile layout problems.
12. Close with the production URL and feedback invitation.

## Narration and Captions

Use a warm, neutral English AI voice. Narration should:

- Use short sentences.
- Avoid technical terms such as RPC, PKCE, database, or OAuth.
- Describe the purpose of an action before the click.
- Leave brief pauses after important actions.

Captions must match the narration, remain within title-safe margins, use high
contrast, and display no more than two lines at once. Deliver a separate `.srt`
caption file for each unique narration edit in addition to burned-in captions.

## Formats and Delivery

Landscape exports:

- Resolution: 1920x1080.
- Aspect ratio: 16:9.
- H.264 MP4 with AAC audio.

Vertical exports:

- Resolution: 1080x1920.
- Aspect ratio: 9:16.
- H.264 MP4 with AAC audio.
- Reframe controls and captions for phone viewing rather than cropping blindly.

Deliverables:

- `prompt-vault-pro-quick-16x9.mp4`
- `prompt-vault-pro-quick-9x16.mp4`
- `prompt-vault-pro-detailed-16x9.mp4`
- `prompt-vault-pro-detailed-9x16.mp4`
- Quick and detailed narration scripts.
- Quick and detailed `.srt` caption files.
- A short beta-tester distribution message containing the app and video links.

## Quality Checks

Before delivery:

- Verify every demonstrated action works in production.
- Confirm no private information appears in any frame.
- Confirm captions match narration and remain readable on mobile.
- Confirm both orientations show the active control clearly.
- Listen for clipping, abrupt edits, and inconsistent volume.
- Check the production URL on the final card.
- Watch each export from beginning to end.

## Success Criteria

A first-time tester should be able to sign in, create and save a prompt, find
it again, copy it, understand optional tags and knowledge files, and know what
feedback to provide after watching the detailed tutorial once.
